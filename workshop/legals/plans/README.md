# Plans

One file per item the skill aims to produce, in a folder by status. Move the file when its status changes.

- `done/`: built and reviewed by the owner. Follow-up work (a region block, a refresh) is listed in the file.
- `in-progress/`: started, not finished. Move the file here when you start.
- `backlog/`: not built yet.

Skill-wide work is in [skill.md](skill.md). Decisions stay in [`PLAN.md`](../PLAN.md); their numbers are cited across the repo.
