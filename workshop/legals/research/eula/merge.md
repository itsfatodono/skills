## Document level (step 4)

- **Words:** median about 4,900 (range 390–14,000). Large about 7,100 (9), mid about 4,300 (6),
  small about 1,800 (7).
- **Carrier:** 18/22 web pages; 2/22 plain-text files (s16, s18); 1/22 PDF (s13); 1/22 a web copy
  that says the binding text is the one shown at install (s06).
- **Structure:** 16/22 number their sections; 1/22 a table of contents (s09); 5/22 a base agreement
  plus modules, product addenda or product-specific pages that win on conflict (s04, s07, s13,
  s19, s22); 9/22 vary clauses or the contracting entity by where the user lives or bought (s01,
  s04, s05, s10, s13, s16, s22, s23, s28); 7/22 one agreement for several products (s03, s04,
  s07, s11, s13, s19, s23).
- **Register:** about 14/22 name the licensor in the third person ("Licensor", the brand, "the
  Company"), about 8/22 mostly "we/you"; 13/22 set the warranty and liability clauses in all
  caps; 2/22 open with a plain-language preface or welcome (s04, s11).
- **Recurring elements:** a dated "last updated" or version line 11/22, a version tag without a
  date 2/22 (s06, s13), none 9/22; a definitions block 6/22 (s02, s05, s13, s15, s16, s27);

  the same page 2/22 (s10, s18).
- **Not sections:** version tags and codes (s04, s06), an archive of previous versions (s10),
  copyright footer lines (s11, s18), s09's table of contents.
