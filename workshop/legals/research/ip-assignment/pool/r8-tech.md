# Pool slice r8-tech: IP Assignment (ip-assignment)

Route: R8 (SEC EDGAR full-text search, `efts.sec.gov/LATEST/search-index`), technology filers. Run 2026-11-12.
Document: agreement by which an individual assigns inventions / IP to the company (PIIA, CIIAA, Employee Invention Assignment and Confidentiality Agreement and similar). Language: en.

## Queries run

Date range 2019-01-03 to 2026-11-01. One query per phrase and form, every page read (100 hits per page).

Deviations from the dispatch:
- The `sics=` parameter is ignored by the API (every SIC value returned the same hits, and `from=0` returns a different, cached result), and `forms=` with a comma list returns only the last form. So each form was queried alone, no `sics=` was sent, and the SIC filter was applied to each hit's `sics` field afterwards (7370-7374, 7379, 7389, 3570-3579, 3670-3679, 4813, 4899, 3663). The first page was requested without `from`.
- Pages were 100 hits; hits whose `file_type` starts with `EX-10` and whose SIC is in the list were kept (424B4 returned no EX-10 hits).
- Phrase pages for "Confidential Information and Invention Assignment" on 10-K, 10-Q and 8-K were read in full but are not itemised exactly above.

## Counts

- EX-10 exhibits in the SIC set fetched and read (HTML stripped, title and first screen, plus a search of the body for an attached agreement heading and first-person assignment text): 1,660, from 336 filers.
- Kept: 46 rows, one per company (latest filing whose exhibit is, or attaches in full, the IP assignment agreement). Rows marked "attached" hold the full agreement as an exhibit inside the same file (rule 6). Standalone: Squarespace, Credo, Procore, Foxx.
- Skipped: 1,614.
  - 1,242 exhibits from 290 other companies: employment agreements, offer letters, separation or transition agreements, retention agreements, severance plans, equity award forms, investor-rights agreements and consulting agreements that only mention the IP agreement or contain an inline invention clause, with no attached form.
  - 372 further exhibits from the 46 kept companies: earlier filings of the same form (one row per company), or other officers' letters of the same company without the attached form.
- Not kept on doubt (attachment not confirmed by heading): Etsy, Veeva, Spire Global, Blend Labs, SailPoint, DoorDash, Fastly, JFrog, Gitlab, Cloudflare.
- Headcount is from the filing's main document where it is a 10-K or S-1 (as filed, text near "employees"); blank for 8-K and 10-Q rows. Datadog's S-1/A and SITO Mobile's 10-K/A (Part III amendment) state none in the text searched ("not found"). Kaltura, Varonis and Proofpoint counts include the qualifiers noted.
- Several exhibits are per-officer copies carrying names and signature blocks; the form text is the same across a company's letters.
