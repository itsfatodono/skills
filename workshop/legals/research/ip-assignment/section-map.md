# ip-assignment: section map

Every extraction-table row mapped to a section id (`merge.md`), the basis of every count. One row may
carry several ids (`a+b`) when it gives several kinds of fact. Marks that are not sections and are
never counted: `host` (a clause of the host agreement that points to the assignment), `signature`
(execution block; counted at document level), `heading` (a heading-only row), `regional` (a
state-law addendum wholly about one law; see `merge.md` *Regional content*). `#2` marks the second row
with the same number in a table.
