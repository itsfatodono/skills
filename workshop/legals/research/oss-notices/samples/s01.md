- Size: Android ~780 package names in 20 licence entries; iOS ~70 names in 33 entries; fonts ~190 entries, one per font. The font part is about three quarters of the words, because the full OFL text repeats in every font entry.
- Register: the company's own words only in the two platform header lines, the LGPL written offer and one model note. The rest is licence text copied verbatim. The header line is all caps; the offer is plain, third person ("TikTok hereby offers").
- Per-entry fields (software parts): licence name as heading; package names in brackets, comma-separated (one name up to hundreds; the Android Apache entry runs to several hundred build artefacts); sometimes a copyright line; sometimes a licence or project URL; then the full licence text. - Per-entry fields (fonts): font name as heading; copyright line with the project or designer URL and any Reserved Font Name; a line naming the licence (OFL 1.1, or Apache 2.0 for the company's own TikTok Sans); then the full licence text.

- Irregularities: the iOS part has no LGPL offer of its own; a Facebook *Android* SDK licence entry appears under iOS; some fonts are listed twice (Cinzel, 源ノ角ゴシック); one font heading is in Japanese script.
