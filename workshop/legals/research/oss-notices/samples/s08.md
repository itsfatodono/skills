## Document
- Shape: one generated page inside the marketing site. Title, a two-sentence intro, a row of three
  figures (package count, licence count, "Last reviewed" date), then a two-column package list
  (710 rows, alphabetical, scoped npm names first), then one block per licence with its full text,
  then "Back to top". Generator not named; uniform rows, SPDX ids, slug anchors (`#mit`,
  `#bsd-2-clause-or-mit-or-apache-20`) and the counts show it is generated (the page itself is an
  Astro build).
- Register: impersonal opener ("The following sets forth attribution notices..."), one warm line of
  thanks; the rest is table data and verbatim licence texts.
- Scope: the npm dependencies of the app, which is a Capacitor (web-wrapped) iOS/Android app
  (`@capacitor/ios`, `@capacitor/android` listed). No native iOS pods or Android Maven libraries,
  no split by platform.
- Per-entry fields: package name | licence. The licence is an SPDX id or an SPDX expression in
  brackets for dual licences ("(MIT OR CC0-1.0)"); it links to that licence's block below. No
  version, no copyright holder, no repository link, no per-package notice text. Mix: about 590
  MIT, 46 ISC, 24 Apache-2.0, 20 BSD-3-Clause, the rest single-digit (BlueOak, MPL-2.0, MIT-0,
  0BSD, CC-BY-4.0, CC0-1.0, Python-2.0, one source-available FSL-1.1-MIT listed alongside).
- Licence blocks: 17, one per distinct licence string (SPDX expressions get their own block), each
  with one text. Texts appear to be copied from one package's LICENSE file rather than the
  canonical text: line wrapping differs between blocks, the BlueOak block opens with a project's
  own note ("All packages under src/ are licensed according to..."), the Apache block ends with the
  appendix boilerplate. Copyright lines are absent from the MIT/ISC/BSD texts (no holder, no
  placeholder); only the Python-2.0 block keeps its embedded copyright history. A dual-licence
  block shows only one of the options' texts (the MIT text under "(MIT OR GPL-3.0-or-later)").
- Recurring elements: "Last reviewed" date; package and licence counts; "Back to top" link.
- Absent: contact, written offer for source code, separate treatment of copyleft or
  MPL components, own warranty disclaimer, statement of how the list was produced, notice
  version or change history.
