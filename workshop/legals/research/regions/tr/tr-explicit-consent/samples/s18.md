## Document
- Shape: one page with two tabs, *Kullanıcı Açık Rıza Metni* and *İşletme Açık Rıza Metni*. Only the user tab is extracted (rule 6); the business tab follows the same template with business data categories. The user text is an all-caps title, a salutation, three opening paragraphs, a bulleted list of data categories, and a one-sentence declaration. It ends with a printed-form block: RIZAM VARDIR / RIZAM YOKTUR, name and date lines.
- Register: formal, legalistic Turkish with long sentences. The opening is second person ("rıza göstermeniz gerekmektedir"), the declaration first person ("hür irademle"). The law is named in full ("6698 Sayılı Kişisel Verilerin Korunması Kanunu") in almost every sentence.
- Recurring elements: controller name, address and trade-chamber registry number in the text; a pointer to the "Şirket Aydınlatma Metni"; a "Son Güncelleme" date at the end of each tab.
- Consent items: one blanket consent for the processing and transfer of all listed data. No purpose is given anywhere; the declaration says only "bu açık rıza metninde belirtilen çerçevede". The single recipient named is a category: contracted cloud service providers abroad. No domestic recipient is named.
- Acceptance: a paper-form block with a choice between "RIZAM VARDIR" and "RIZAM YOKTUR", a name line and a date line. It is one choice for the whole text, and the page does not say how the app takes it.
