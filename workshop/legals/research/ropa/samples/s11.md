## Document
- Shape: a register web page (one-sentence intro, then two tables: "Public-facing operations"
  with columns Area, Description of the processing activity, Privacy statement link; and
  "Internal operations" with Area and Description). Each activity links a record PDF (served
  via `/@@download/file`). Read: the register page and three records (Online Contact Us Form,
  the first; Selection procedure for statutory staff; EEA Catalogue of Spatial Data, core work).
  All three use one 12-item numbered table (Nr., Item, Description); the first adds a
  "1.0 Last update" line, and the processor field of the HR record still shows a drafting
  placeholder ("[Complete with contact details]").
- Status: the public record per operation.
- Activities: 21 records (11 public-facing, 10 internal).
- Grouping: public-facing vs internal operations, then by area code (COM, HR, IT, ADS).
- Unit of one row: one processing operation (a form, a system, a procedure).
- Scope: controller records; processors named inside.
- Record fields: 1.0 Last update; 1.1 Reference number; 1.2 Controller; 1.3 Joint controller;
  1.4 Processor; 1.5 DPO; 1.6 Purpose; 1.7 Categories of persons and data; 1.8 Time limit for
  keeping the data; 1.9 Recipients; 1.10 Transfers to third countries; 1.11 Security measures;
  1.12 Measures for providing additional information (rights).
- Absent: legal basis as a field, data source, DPIA flag, special-category field.
- Register: formal third person ("the EEA"), long paragraphs with dashed lists.
- Recurring elements: reference code DP.<area>.<year>.<n>; "Modified" date on the register page;
  privacy statement link per public-facing activity.
- Size: register page about 300 words; records 556, 1,466 and 1,541 words.
