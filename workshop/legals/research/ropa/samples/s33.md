## Document
- Shape: regulator model inside a 40-page guide. Only two parts are the sample: the guide
  section "Data Inventory Maps, Data Flow Diagrams and Other Registers" (pp. 23-25, under "Risk
  Identification and Mapping"), which says what the inventory should contain, and Annex C
  (pp. 38-39), which shows two options: a Data Inventory Map (one-sheet grid, picture of a
  spreadsheet) and a Data Flow Diagram (swim-lane chart), each with a Pros / Cons box.
- No blank form: Annex C gives only a filled worked example, stamped "Illustrative". The grid
  has a title bar "Personal Data Inventory", seven grouped header bands (Collection, Use,
  Disclosure to External Parties in Singapore, Storage, Transfer to External Parties outside
  Singapore, Disposal & Archival) and one example row (an Advertising and Marketing department).
- Status: blank model (illustrative worked example, no real record).
- Activities: 1 example row in the map; 1 example department (HR) in the flow diagram.
- Grouping: by department; columns grouped by data life-cycle stage (collection, use,
  disclosure, storage, transfer abroad, disposal).
- Unit of one row: a department with the personal data it holds (all purposes of that
  department in one cell).
- Scope: controller only; the guide's vocabulary is "personal data under the organisation's
  possession or control". No processor record.
- Record fields: No.; Department; Personal Data; Collection Purpose; Data Owner; Data Source;
  Collection Medium; Users of Personal Data and Purpose of Usage; Access to Personal Data;
  External Parties and Purpose of Transfer / Disclosure; Transfer Mode; Physical Storage;
  Electronic Storage; External Parties; Transfer Mode; Retention Period; Disposal Methods.
- Absent: legal basis or consent column (consent goes to a separate consent register), data
  subject categories as a column (named inside Personal Data, "Members:"), security measures
  column beyond storage description, data classification column (the guide asks for it but
  the grid has none), DPIA flag, controller/DPO block, version or review date.
- Register: guide text is advisory third person ("organisations should", "as good practice");
  the grid holds labels and short noun-phrase entries only.
- Recurring elements: "Illustrative" stamp on both examples; Pros / Cons boxes under each
  option; links to other PDPC tools (inventory map template, consent registry template).
- Size: section about 450 words; Annex C about 200 words of text plus a 1 row by 17 column
  grid and one diagram.
