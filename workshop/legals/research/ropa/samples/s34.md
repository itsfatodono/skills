## Document
- Shape: a 2-page Word template: disclaimer banner; title; a short introduction (legal duty,
  who must keep a record, why it helps); a field-guidance table (Field, Details / Guidance);
  a header table (organisation, DPO, date completed / last reviewed); the record table with
  three filled example rows and empty rows; closing disclaimer with the regulator's contacts.
- Status: blank regulator model with examples.
- Activities: 3 example rows.
- Grouping: none.
- Unit of one row: a processing activity ("one row each").
- Scope: controller and processor in one table (a role column marks each row; the third example
  is a processor activity).
- Record fields (guidance table): Processing activity name; Controller (or joint controller);
  Processor; Purpose; Legal basis; Categories of data subjects; Categories of personal data;
  Recipients; International transfers; Retention period / deletion criteria; Security measures;
  Systems / tools used; DPIA required?; Notes / comments / changes. The record table uses 11 of
  them (no systems or DPIA column; DPIA status goes in Notes).
- Absent: data source, special-category condition, rights, automated decisions, DPO contact per
  row.
- Register: plain, "you"; guidance as questions ("Why is the personal data being processed?")
  and "e.g." lists.
- Recurring elements: two disclaimers ("general guidance only", "does not constitute legal
  advice").
- Size: about 760 words.
